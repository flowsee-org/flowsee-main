# استودیو فلوسی

وب‌سایت فارسی و راست‌چین استودیو فلوسی؛ ساخته‌شده با Laravel و PHP، با تمرکز بر معرفی خدمات، نمایش نمونه‌کارها و ارائهٔ یک مطالعهٔ موردی مستقل.

[راهنمای کامل پروژه در ویکی GitHub](https://github.com/flowsee-org/flowsee-main/wiki)

## امکانات

- صفحهٔ اصلی واکنش‌گرا با معرفی خدمات، نمونه‌کارها و راه‌های ارتباطی
- پیش‌نمایش پروژه‌ها و مطالعهٔ موردی ابراهیمی، همراه با گالری و نمایش بزرگ تصاویر
- فرم بریف پروژه با اعتبارسنجی و ثبت امن درخواست در پایگاه داده
- پنل مدیریت Filament برای مشاهده و جست‌وجوی لیدها، فیلتر بر اساس خدمت و بازهٔ تاریخ و تغییر وضعیت پیگیری
- فونت‌ها، تصاویر و اسکریپت‌های میزبانی‌شده در خود پروژه
- مسیر سلامت Laravel در `/up` و هدایت نشانی‌های قدیمی به صفحات فعلی

برای ورود به پنل، پس از استقرار نخست یک مدیر را روی سرور بسازید. دستور زیر نام، ایمیل و گذرواژهٔ قوی را به‌صورت تعاملی می‌پرسد و حساب را در جدول کاربران ذخیره می‌کند:

```bash
cd "$(dirname "$(readlink -f /var/www/flowsee-live)")"
php8.4 artisan flowsee:admin:create
```

ثبت‌نام عمومی فعال نیست و حساب‌های عادی اجازهٔ ورود به پنل را ندارند.

## فناوری‌ها

- PHP 8.3 یا جدیدتر؛ استقرار و CI پروژه از PHP 8.4 استفاده می‌کنند
- Laravel 13
- Blade، CSS و JavaScript بدون فرایند build سمت کاربر
- Composer برای وابستگی‌های PHP؛ Node.js و npm برای اجرای سایت لازم نیستند

## اجرای محلی

پیش‌نیازها: PHP 8.3+ با افزونه‌های موردنیاز Laravel، Composer و Git.

در PowerShell، از ریشهٔ پروژه اجرا کنید:

```powershell
composer install
if (!(Test-Path .env)) { Copy-Item .env.example .env }
php artisan key:generate
php artisan serve
```

سایت به‌طور پیش‌فرض در `http://127.0.0.1:8000` در دسترس است. برای اجرای تست‌ها:

```powershell
composer test
```

اگر `.env` از قبل تنظیم شده است، آن را با نمونه جایگزین نکنید. تنظیمات محلی را در `.env` انجام دهید؛ این فایل نباید وارد Git شود. برای راهنمای توسعه، معماری، محتوا، انتشار و عیب‌یابی، [ویکی پروژه](https://github.com/flowsee-org/flowsee-main/wiki) را ببینید.

## مسیرها

| نشانی | توضیح |
| --- | --- |
| `/` | صفحهٔ اصلی |
| `/projects/ebrahimi` | مطالعهٔ موردی ابراهیمی |
| `/admin` | پنل مدیریت لیدها؛ نیازمند ورود مدیر |
| `/admin/login` | ورود مدیر پنل |
| `/up` | بررسی سلامت Laravel |
| نشانی‌های HTML قدیمی | هدایت دائمی به صفحهٔ اصلی یا مطالعهٔ موردی |

## ساختار اصلی

```text
app/                         کد برنامهٔ Laravel
routes/web.php               مسیرهای وب و هدایت نشانی‌های قدیمی
resources/views/             قالب‌های صفحهٔ اصلی و مطالعهٔ موردی
public/assets/css/           شیوه‌نامه‌های اصلی و واکنش‌گرا
public/assets/js/site.js     تعاملات صفحه، گالری و فرم بریف
public/assets/               تصاویر، فونت‌ها و کتابخانه‌های سمت کاربر
tests/Feature/               تست‌های مسیرها، محتوا و دارایی‌های محلی
ops/                         ابزار استقرار و تست‌های وب‌هوک
.github/workflows/deploy.yml گردش‌کار CI و انتشار
wiki/                        صفحات مستندات پروژه
reference/                   منابع طراحی و آرشیوهای مرجع
```

نسخهٔ منبع صفحات ویکی نیز در پوشهٔ `wiki/` نگهداری می‌شود. برای مشاهدهٔ راهنماهای منتشرشده، به [ویکی پروژه در GitHub](https://github.com/flowsee-org/flowsee-main/wiki) بروید.
